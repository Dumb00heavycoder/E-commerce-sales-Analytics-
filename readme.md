# E-Commerce Sales Analytics

## Overview

This project focuses on analyzing e-commerce sales data using Python and Pandas.

The goal is to clean, transform, and analyze sales data to understand product performance, customer behavior, and business trends.

The project covers data cleaning, feature engineering, product analysis, customer analysis, and time-based sales analysis.
